# HantiLink – Global B2B Marketplace

## About the Project
HantiLink is a simple B2B marketplace website that connects buyers and suppliers. It allows users to view products, search for products, and manage product listings.

## Technologies Used
- HTML – Website structure
- CSS – Website design and layout
- JavaScript – Website functionality
- LocalStorage – Saving product information in the browser

## Main Features
- View available products.
- Search for products.
- Add new products.
- Delete product listings.
- View information about HantiLink.
- Responsive design for different screen sizes.

## Project Pages
1. `index.html` – Homepage and marketplace.
2. `dashboard.html` – Add and manage products.
3. `about.html` – Information about the project.

## How to Run the Project
1. Download or clone the project.
2. Open the HantiLink folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Start exploring the website.

## Data Storage
HantiLink uses browser LocalStorage to save product information. The data stays in the same browser on the same device and is not shared between different users.

## Project Purpose
This project was created to practise HTML, CSS, JavaScript, website design, and basic data storage.
